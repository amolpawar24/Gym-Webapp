# 🏋️ Gym-Webapp

A modern and responsive **Gym Web Application** built with **React.js** and **Firebase**.

The project is designed to provide a clean and interactive web experience for a gym/fitness application, with reusable React components, responsive UI, smooth scrolling, and Firebase integration.

🌐 **Live Demo:** https://gym-app-three-rho.vercel.app/

---

## 📌 About The Project

**Gym-Webapp** is a frontend web application developed using React.js.

The application focuses on building a responsive and user-friendly gym website with a component-based architecture. It uses React for the frontend, Firebase for backend services/integration, and React Scroll for smooth navigation between sections.

This project was created as a practical React.js project to strengthen frontend development skills and understand how a real-world React application is structured and deployed.

## ⚙️ Installation & Setup

Follow the steps below to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/amolpawar24/Gym-Webapp.git
```

### 2. Navigate to the Project

```bash
cd Gym-Webapp
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm start
```

The application will run at:

```text
http://localhost:3000
```

---

## 🔥 Firebase Configuration

This project uses Firebase.

If you are setting up the project locally, configure your Firebase project according to your application's Firebase setup.

### Environment Variables

If Firebase credentials are stored using environment variables, create a `.env` file:

```env
REACT_APP_FIREBASE_API_KEY=your_api_key
REACT_APP_FIREBASE_AUTH_DOMAIN=your_auth_domain
REACT_APP_FIREBASE_PROJECT_ID=your_project_id
REACT_APP_FIREBASE_STORAGE_BUCKET=your_storage_bucket
REACT_APP_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
REACT_APP_FIREBASE_APP_ID=your_app_id
```

> Never commit private credentials, API secrets, or sensitive environment configuration to GitHub.
